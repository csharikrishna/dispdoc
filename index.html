COMMON QUESTIONS

Frequently Asked Questions

Why is this better than watching 4K YouTube test videos?

YouTube compresses video with lossy codecs (AV1/VP9) which truncates near-black IRE gradations into muddy macroblocks. DisplayDoctor renders uncompressed mathematical gradients directly on your GPU canvas with 1:1 pixel mapping.

Why does my 8-bit monitor show 24-bit?

Monitors are rated by bits per color channel (8 bits Red + 8 bits Green + 8 bits Blue). The total color depth across all 3 channels is 24 bits (16.7 million colors). DisplayDoctor formats this as 8-bit SDR to directly match Windows Advanced Display Settings and monitor manufacturer specifications.

How does the 0-Nit True Black test work?

The test sets every pixel to RGB(0,0,0) in exclusive fullscreen mode. In an OLED panel, individual pixels completely shut off with 0 emitted photons. If you see glow, the display controller is leaking bias current or the panel is not true OLED.

Does DisplayDoctor install anything on my machine?

No. It is a 100% client-side web application built with zero dependencies. No software downloads, no browser extensions, and no telemetry data transmitted.

Photosensitivity & Visual Stress Advisory

DisplayDoctor Pro contains rapid strobe, high-frequency chromatic flashes, and visual stress patterns engineered for display panel testing.

These patterns may cause discomfort or seizures in photosensitive individuals. Discontinue testing immediately if you experience dizziness, nausea, headache, or visual fatigue.
