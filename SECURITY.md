# Security Policy

DisplayDoctor Pro is a static, client-side site. It has no server, no accounts,
and no data collection. Security issues are still possible (for example, script
injection through a crafted URL, or a compromised dependency in the dev
tooling).

## Supported versions

Only the latest version on the `main` branch, as deployed to GitHub Pages, is
supported.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, use
[GitHub private vulnerability reporting](https://github.com/csharikrishna/dispdoc/security/advisories/new).

Include steps to reproduce and the potential impact. You should get an
acknowledgement within a week.
